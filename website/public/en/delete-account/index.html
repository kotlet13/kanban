Jivie · Account and data

Delete your self-hosted account

The process takes place on the server where your account lives.

Local-only use has no server account. This page is for accounts on a self-hosted Kanboard server with the FamilyHub plugin. TriparNA cannot access those accounts simply because you use Jivie.

Export what you want to keep before deletion. Jivie currently uses the same user account as Kanboard: deleting that account also removes its Kanboard sign-in. Signing out or uninstalling the app does not delete the server account.

Open your server’s deletion page

Enter only the base address of your Kanboard server. This page prepares a link; it does not connect to the server or send a deletion request. You sign in and confirm on your own server.

Do not enter passwords, sign-in codes or invitation links here.

Continue on:

Open my server ↗

Check the address before signing in. A compatible FamilyHub version with account deletion enabled is required.

Before you confirm

Your server shows the affected data and any ownership issues that need resolving. Personal synchronized data, access and shared contributions are handled according to that preview. Shared spaces or records belonging to other people must not disappear as a hidden side effect. The process may require an ownership transfer or an explicit choice for shared structures.

Records created by other members remain, including edits you made to their content. A shared shopping list or financial account needed by other members can remain after an explicit choice, with identifying fields removed; the preview explains any retained balance. Some older Kanboard tasks contain contributions from several people and require resolving those dependencies before deletion.

If your server does not support this page

Ask its operator to update FamilyHub and enable the self-hosted deletion feature. This public site cannot perform deletion on an incompatible or unreachable server and does not show a deletion as complete without that server’s confirmation.

Copies and backups

Deletion cannot recall exports or copies other members already obtained. The server operator handles logs and server backups. Standalone local personal data is separate from the server account. Managed hosting is not offered at this stage and will have its own published rules if introduced.
