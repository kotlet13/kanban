## 5. Druge potrjene širše poti in omejitve

1. **Recovery fallback zavestno izgubi ozkost hintov.** [collaboration_sync_actions.dart:264–309](/Users/anzenovsak/Git/kanban/lib/organizer/data/collaboration_sync_actions.dart:264) za detached crypto work ali payment recovery kliče `_performSync(changes:null)`. 2. **Metadata cache ne zajame glavnega pull/attestation dela.** Novi group se konča pred cursor/content/finance. 3. **Odvisnosti so poslovno različne.** Content task derivation lahko potrebuje finance writerja; table/idea payload potrebuje blob; linked payment objavo source/target; parent project potrebuje parent finance/read grant. Te odvisnosti je treba navesti v work planu, ne jih preimenovati v vedno-fullsync ali odstraniti kot odvečne.
4. **Coalescing je lokalen, ne celoten račun/IP.** Centralni sync, protection, autoapproval, documents, account/key wizard in payments imajo lastne vhodne točke. 1. **Najprej ločiti change evidenco po pomenu.** Poslovni content/finance/documents sequence, dejanska permission/device-roster sprememba, monotoni receipt/observation journal in display metadata ne smejo avtomatsko pomeniti istega scope-access work plana.
