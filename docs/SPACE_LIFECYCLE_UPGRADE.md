# Space lifecycle upgrade — implementation and evidence

Implemented local and shared archive/delete controls in the title's ⋯ menu and settings, named counted deletion previews with safe Cancel, and initially collapsed archived organization lists. Full-scope deletion remains owner-only; inline project deletion preserves existing editor rights. Normal household/organization member removal revokes descendant direct access, guarded against child ownership. Accounts and device registrations are preserved.

Shared deletion removes a closed dependency graph transactionally, retains permanent scope/record tombstones and immutable request hashes, and queues private-image unlink after commit. External financial dependencies block deletion. Local SQLite deletion rechecks the exact preview inside the transaction, removes target records/boards/drafts/unreferenced photos and advances idea/garden revision floors. Default Personal, unrelated spaces/accounts and shared photo references survive. Bound or publication-pending local spaces require resolution. Local project deletion removes children and tied costs; immutable pending private operations retain required photo bytes until synchronization/recovery completes.

Archived local/shared projects guard task, event, idea and task-linked finance writes, including stale editors and direct storage writes. Archive retains readable history; restoration permits new edits without replaying skipped overdue reminders. Revocation hides live cached content and cancels delivery while preserving own drafts/unsent operations for export.
